# K230 + STM32F103C8T6 钢球平衡系统说明

## 1. 系统组成

本系统由K230摄像头、STM32F103C8T6最小系统板、一个180°舵机、水管、
独立5 V舵机电源、OLED和USB-TTL组成。

K230负责识别钢球并运行二维恒速度卡尔曼滤波。STM32负责解析坐标、计算PID、
限制控制角度和速度，并通过TIM3_CH1输出50 Hz PWM控制舵机。

控制目标默认是320×320画面中的`(160,160)`。当前机械结构只进行一维平衡，
所以PID只使用目标x与钢球x之间的误差；目标y用于K230画面标记。

## 2. 接线

### 2.1 K230与STM32

| K230 | STM32F103C8T6 | 说明 |
|---|---|---|
| GPIO3 / UART1_TX | PA10 / USART1_RX | 发送钢球状态 |
| GPIO4 / UART1_RX | PA9 / USART1_TX | 接收目标点 |
| GND | GND | 必须共地 |

两端均配置为115200、8数据位、无校验、1停止位。

### 2.2 电脑调参串口

| USB-TTL | STM32F103C8T6 |
|---|---|
| TX | PA3 / USART2_RX |
| RX | PA2 / USART2_TX |
| GND | GND |

USB-TTL必须使用3.3 V逻辑电平。

### 2.3 舵机

| 舵机线 | 连接位置 |
|---|---|
| 信号 | PA6 / TIM3_CH1 |
| 电源 | 独立5 V电源正极 |
| 地 | 独立电源地，同时连接STM32和K230地 |

不要用STM32或K230的3.3 V引脚给舵机供电。建议在舵机电源附近并联
470～1000 μF电解电容和0.1 μF去耦电容。

### 2.4 OLED和ST-Link

| 功能 | STM32引脚 |
|---|---|
| OLED SCL | PB8 |
| OLED SDA | PB9 |
| 状态LED | PA1，低电平点亮 |
| ST-Link SWDIO | PA13 |
| ST-Link SWCLK | PA14 |

## 3. K230部署

需要复制到K230 SD卡：

```text
电脑：k230_artifacts/steel_ball_yolov8n_320_new.kmodel
目标：/sdcard/models/steel_ball_yolov8n_320_new.kmodel

电脑：k230/steel_ball_yolov8n_320_k230.py
目标：/sdcard/steel_ball_yolov8n_320_k230.py
```

在CanMV IDE中打开脚本并运行。启动信息应显示：

```text
图像/模型坐标: 320x320
UART1: GPIO3=TX GPIO4=RX 115200 8N1
```

画面标记：

- 绿色框：普通YOLO检测框；
- 紫色框：当前被跟踪的钢球；
- 黄色圆：检测框原始中心；
- 青色十字：卡尔曼滤波位置；
- 红色十字：目标点；
- 白线：目标点与钢球位置之间的偏差。

跟踪状态：

- `MEAS`：当前帧有真实检测；
- `PRED`：短时漏检，正在使用卡尔曼预测；
- `LOST`：连续漏检超过3帧，坐标无效；
- `RESET`：连续漏检达到10帧，滤波器已经重置。

## 4. STM32 Keil工程

打开：

```text
keil/Project.uvprojx
```

工程配置：

- Device：STM32F103C8；
- 标准外设库：V3.5.0；
- 启动文件：`startup_stm32f10x_md.s`；
- 主频：72 MHz；
- 下载器：ST-Link；
- 下载接口：SWD；
- Flash：64 KB；
- SRAM：20 KB。

新增代码分组：

- `Control`：PID和平衡状态机；
- `Protocol`：K230二进制协议和电脑调试命令；
- `Hardware`：双串口、PWM、舵机和状态LED；
- `System`：TIM4毫秒系统时基。

编译后先不要安装舵臂，下载程序并用示波器或逻辑分析仪检查PA6：

- 周期约20 ms；
- 中位脉宽约1556 μs，对应实测机械中位100°；
- 闭环范围约1500～1611 μs，对应90°～110°。

## 5. 电脑调参命令

串口助手配置为115200 8N1，每条命令发送换行。

```text
TARGET 160 160
PID 0.060 0.003 0.020
ENABLE
DISABLE
NEUTRAL
DIRECTION 1
DIRECTION -1
STATUS
HELP
```

命令说明：

- `TARGET x y`：设置0～319范围内的目标点，并同步到K230；
- `PID kp ki kd`：在线修改PID，修改后重新等待5帧真实测量；
- `ENABLE`：允许自动进入闭环；
- `DISABLE`：关闭闭环并缓慢回中；
- `NEUTRAL`：清空PID并重新等待5帧真实测量；
- `DIRECTION 1/-1`：改变舵机控制方向；
- `STATUS`：显示坐标、误差、PID三项、角度、PWM、CRC、缓冲区溢出、
  失效保护次数、通信超时次数和当前UART掉线标志；
- `HELP`：显示命令列表。

参数只保存在RAM中，重新上电后恢复默认值。

## 6. 默认控制参数

```text
目标点：160,160
Kp：0.060
Ki：0.003
Kd：0.020
误差死区：±2像素
PID输出：±10°
舵机安全范围：90°～110°
机械中位角：100°
正常最大速度：60°/秒
失效回中速度：30°/秒
通信超时：150 ms
进入闭环所需真实测量：连续5帧
```

PID只在收到一帧新视觉坐标时重新计算；20 ms控制任务负责让舵机按限速逐步靠近
目标角度。这样不会把10～30 Hz视觉数据错误地重复当成50 Hz新测量。

控制层还会根据钢球到目标点的横向距离动态限制最大倾角。默认误差位于±2像素
死区内时最大倾角为0°；误差从2像素增加到100像素时，允许的最大倾角从0°
线性增加到10°；误差超过100像素后保持10°上限。因此钢球越接近中心，水管
动作越小，远离中心时才允许更大的回球角度。对应参数位于`BalanceControl.h`：

```c
#define BALANCE_FULL_TILT_ERROR_PIXELS     100.0f
#define BALANCE_MAX_TILT_DEG               10.0f
```

`STATUS`输出中的`LIMIT`就是当前由距离计算得到的动态最大倾角。

## 7. 首次联调顺序

1. 不装舵臂，确认PA6的50 Hz PWM和约1556 μs中位。
2. 连接舵机但不连接水管，执行`NEUTRAL`，确认机械中位。
3. 连接K230和STM32，执行`STATUS`，确认`FRAME`持续增加且`CRC`不增加。
4. 移动钢球，确认OLED的X和K230滤波坐标一致。
5. 发送`TARGET 140 160`，确认K230红色目标十字移动并收到ACK。
6. 把钢球放到目标左侧，低增益观察水管是否让钢球向右移动。
7. 如果方向相反，发送`DIRECTION -1`，不要修改误差公式。
8. 先使用`PID 0.020 0 0`测试，再逐步增加Kp。
9. 出现振荡时降低Kp并逐步增加Kd。
10. Kp、Kd稳定后再加入很小的Ki消除静态偏差。

## 8. 失效保护

以下任一情况都会停止PID并让舵机以30°/秒缓慢回到100°：

- 150 ms没有收到K230有效通信帧；
- K230发送无效坐标；
- 连续漏检超过3帧；
- 坐标超出0～319；
- 电脑发送`DISABLE`。

通信或识别恢复后，必须重新连续收到5帧真实测量才会进入闭环，防止系统在
临界状态下反复启停。

## 9. 状态LED

- 熄灭：人工禁用；
- 每秒短闪：等待足够的真实测量；
- 常亮：正常闭环；
- 约200 ms闪烁：短时预测；
- 快速闪烁：丢球或通信失效。

OLED第4行在坐标无效时显示`LOST`，在超过150 ms没有收到K230数据时显示
`UART`，便于区分“视觉仍通信但已经丢球”和“物理串口/供电连接中断”。

## 10. 重要安全提示

- 第一次上电必须拆下舵臂或断开水管连杆；
- 确认舵机中位、方向和限位后再安装钢球；
- 调参从小Kp、Ki=0、Kd=0开始；
- 不要取消90°～110°软件限位；
- 不要在主控制循环中加入长时间`Delay_ms`；
- 舵机动作导致复位时，优先检查供电、共地和电源去耦，而不是修改PID；
- 最终参数必须根据实际水管、钢球、舵机和连杆机构现场整定。
